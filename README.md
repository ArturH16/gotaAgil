#Gota Ágil
Gota Ágil é uma plataforma que conecta doadores/possíveis doadores com hemocentros,
que buscam angariar mais voluntários para doarem sangue. A aplicação busca resolver o 
problema da descentralização das informações sobre doação de sangue, unindo tudo num
único de lugar, de maneira intuitiva e fácil uso. Do lado do hemocentro, o alcance de 
suas campanhas pode ser ampliado, e poder dimensionar o número de profissionais envol
vidos em cada campanha.
